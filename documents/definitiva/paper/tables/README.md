# Additional file 2 Complete numerical results

All rows derive from 20261018_definitiva. unit identifies the population; sample is depurada (cleaned) or completa (complete); case identifies C1–C5/C7–C9. n is the analytical sample size. In sensitivity tables, complete-case metadata supplies its own n. Coefficients b use recorded Rubin uncertainty; indirect point/interval fields use the stated bootstrap procedure. Blank fields are unavailable, not zero. Delta and country omissions have no new confidence intervals. Quantities with a root suffix retain that root; C8 totals must not mix roots. B counts bootstrap attempts; actual_imputations=0 in complete-case adapters. Simulation datasets have different designs and denominators and must not be pooled. Every numerical column remains unrounded.

coverage: all 144 combinations and reasons. coefficients: all main SEM paths. indirect_quantities: all primary products/joint quantities. sensitivity_quantities and sensitivity_coefficients: all common scenarios. country_influence: all fixed-imputation omissions, including root-specific quantities. scenario_states: availability of 1,024 scenarios. cohorts: sample/exclusion sizes. missingness/descriptives: current reported summaries, whose method is recorded in task originals. serial_comparison: C7/C9 decomposition. simulation_atlas and simulation_joint: separate designs. transport_C1: current predictive record (unavailable where measurement/cohort conditions fail). Task originals in the atlas retain further diagnostics and all complementary methods.
